Set a device parameter value in Ableton Live via AbletonOSC.

Requires an active connection to Ableton Live with AbletonOSC installed. Use this to control effect or instrument parameters on a track — for example, adjusting a filter cutoff or reverb mix on a device.

Parameters:
- trackIndex: Track index in Ableton (0-based)
- deviceIndex: Device index on the track (0-based)
- paramIndex: Parameter index within the device (0-based)
- value: Parameter value (normalized 0.0 to 1.0)

Returns:
- Confirmation of the parameter change with track/device/param indices and value
