# Dr.C Terminal launchers

| OS | Double-click / run |
|----|---------------------|
| **macOS** | `Dr.C-Terminal.command` |
| **Linux** | `chmod +x Dr.C-Terminal.sh && ./Dr.C-Terminal.sh` |
| **Windows** | `Dr.C-Terminal.bat` |

From repo root:

- macOS / Linux: `./scripts/launch-drc-terminal.sh [work-folder]`
- Windows: `scripts\launch-drc-terminal.bat`

Default work folder: `~/lac-workshop-demo` (created if missing).

Full install steps: **[GET-STARTED.md](../GET-STARTED.md)**
