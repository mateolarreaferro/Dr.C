# Quick Start: Polyphonic Feature

## 🎵 30-Second Test

1. Open `http://localhost:8080/photo_multi_engine_complete.html`
2. Load any image into Slot A
3. Click **"Clone Last Image to All Slots"** button
4. Click **"2-Part Invention"** button
5. Start Slots A and B scanning
6. **Listen**: Two voices playing the same image at different speeds!

---

## 🎼 Three Quick Presets

### 2-Part Invention (Simple)
- **2 voices** (Slots A + B)
- Slot A: normal speed (1×)
- Slot B: double speed (2×), 25% offset
- **Sound**: Interlocking melodic lines (Bach-style)

### 4-Voice Fugue (Complex)
- **4 voices** (all slots active)
- Different speeds: 1×, 0.75×, 1.5×, 0.5×
- Staggered phases: 0%, 20%, 40%, 60%
- **Sound**: Rich polyphonic texture

### Canon (Round)
- **4 voices** (all slots active)
- Same speed (1×), staggered phases
- Entry points: 0%, 25%, 50%, 75%
- **Sound**: "Row, Row, Row Your Boat" effect

---

## 🎚️ Manual Controls (Per Slot)

**Scan Speed** (0.25× to 4×)
- 0.5× = half speed (slower)
- 1.0× = normal speed
- 2.0× = double speed (faster)

**Phase Offset** (0% to 100%)
- 0% = start at beginning
- 50% = start at middle
- 100% = start at end/wrap

---

## 🔧 How It Works

**Same image, different interpretations**:
- Each slot scans the SAME image
- At different SPEEDS (temporal variation)
- From different STARTING POINTS (phase variation)
- With different TIMBRES (engine variation)
- With different RHYTHMS (phrase mode variation)
- With different ARTICULATIONS (ADSR variation)

**Result**: Polyphonic texture from a single source image.

---

## ✅ What You Should Hear

### 2-Part Invention
- **Two distinct melodic lines**
- Slot A plays at normal speed
- Slot B plays twice as fast, slightly offset
- Lines weave together (counterpoint)

### 4-Voice Fugue
- **Four simultaneous voices**
- Each at different speed
- Complex rhythmic relationships
- Rich harmonic texture

### Canon
- **Same melody, staggered entries**
- Like singing "Row, Row, Row Your Boat" in a round
- Each voice enters 25% apart
- Creates harmonic overlap

## 🎨 Creative Tips

**Combine with other features**:

1. **+ Phrase Mode**: Each voice plays/rests independently
   - Slot A: plays 4 beats, rests 2
   - Slot B: plays 8 beats, no rest
   - → **Rhythmic counterpoint**

2. **+ ADSR Envelopes**: Different articulations
   - Slot A: fast attack (percussive)
   - Slot B: slow attack (swelling)
   - → **Textural contrast**

3. **+ Different Engines**: Timbral variety
   - Slot A: FM (bright, metallic)
   - Slot B: Granular (textured, organic)
   - → **Heterogeneous ensemble**

4. **+ Scale Quantization**: Harmonic unity
   - Lock all voices to Pentatonic scale
   - → **Guaranteed consonance**
